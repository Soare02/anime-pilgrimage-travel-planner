## 核心业务流程图

```mermaid
sequenceDiagram
    participant User as 用户
    participant View as 视图层
    participant Store as Pinia Store
    participant Data as 数据处理层
    participant External as 外部服务

    rect rgb(26, 58, 92)
        Note over User,External: 🅰️ 作品信息获取
        User->>View: 输入关键词/Bangumi ID
        View->>Store: dispatch searchByKey / searchBangumi
        Store->>Data: 调用 API 模块
        Data->>External: Bangumi 搜索 / Anitabi 取景地
        External-->>Data: 返回作品元数据 + 地标Geo列表
        Data-->>Store: 更新 bangumi + points
        Store-->>View: 地图标注 + Dock 展示
    end

    rect rgb(42, 42, 74)
        Note over User,External: 🅱️ 客户端路线规划 (Turf.js)
        User->>View: 勾选地标 + 设置天数
        View->>Store: toggleCheck + set days
        User->>View: 点击"生成路线"
        View->>Store: dispatch generateItinerary
        Store->>Data: planRoute(points, days)
        Data->>Data: K-means 聚类 + 最近邻排序
        Data-->>Store: itinerary[] (每日地标排序)
        Store-->>View: 地图绘制折线 + 分配 day-color
    end

    rect rgb(58, 42, 74)
        Note over User,External: 🅲 AI 路线规划 (混合方案)
        User->>View: 设置 AI 方案 (Cloud/Local/Agent)
        View->>Store: updateAiConfig → localStorage
        User->>View: 点击"AI 生成行程"
        View->>Store: dispatch generateLibraryItinerary
        Store->>Data: generateAIRoute(days, landmarks, config)

        alt Cloud 方案
            Data->>External: POST /ark/bots → Volcengine 豆包
            External-->>Data: 完整 Markdown 行程
        else Local 方案
            Data->>External: POST localhost:11434 → Ollama
            External-->>Data: 完整 Markdown 行程
        else Agent 方案 (LangGraph)
            Data->>External: POST /api/agent/plan → FastAPI
            External->>External: LangGraph Pipeline (4个节点)
            Note over External: info_retriever →<br/>Tavily 联网检索 + RAG 召回<br/>+ MiMo 视觉分析
            Note over External: routing_specialist →<br/>地理路由 + 天气适配
            Note over External: anime_expert →<br/>名场面时段 + 拍照指南
            Note over External: supervisor_editor →<br/>合理性审查(≤3轮修正)<br/>→ Markdown 终稿
            External-->>Data: 流式 Markdown 行程
        end

        Data-->>Store: libraryAiResponse += chunk
        Store-->>View: 实时渲染 Markdown
        Store->>Store: saveRouteHistory → localStorage
    end
```

## 关键模块对应关系表

| 功能域 | 视图层 | 状态层 (Store 域) | 数据处理层 | 外部依赖 |
|--------|--------|-------------------|------------|----------|
| **作品搜索** | `SearchPanel` | `searchResults`, `searching` | `searchBangumiByKey()` | Bangumi API (bgm.tv) |
| **巡礼数据获取** | `SearchPanel` | `bangumi`, `points` | `fetchBangumiLite()`, `fetchBangumiPointsDetail()` | Anitabi API |
| **客户端路线** | `MapView` (折线) | `itinerary`, `days` | `planRoute()` (Turf.js K-means + 最近邻) | Turf.js (本地计算) |
| **AI Cloud路线** | `CoordinateLibrary` | `libraryAiResponse` | `generateAIRoute()` → `/ark/bots` | Volcengine Ark 豆包 |
| **AI Local路线** | `CoordinateLibrary` | `libraryAiResponse` | `generateAIRoute()` → `localhost:11434` | Ollama / LM Studio |
| **AI Agent路线** | `CoordinateLibrary` | `libraryAiResponse` | `generateAIRoute()` → `/api/agent/plan` | FastAPI + LangGraph + DeepSeek |
| **Agent-联网检索** | (后端) | — | `get_anime_scene` (Tavily) | Tavily Search API |
| **Agent-视觉分析** | (后端) | — | `analyze_anime_scene_image` (MiMo) | MiMo v2.5 视觉模型 |
| **Agent-RAG知识库** | `RagAdminPanel` | — | ChromaDB 向量召回 + BGE Rerank | 本地 ChromaDB |
| **地标收藏** | `CoordinateLibrary` | `coordinateLibrary` | 纯状态管理（无数据处理） | localStorage |
| **地图展示** | `MapView` | `selectedPointId`, `compareData` | 纯 Leaflet 操作（无数据处理） | Leaflet + CartoDB/高德瓦片 |
| **路线历史** | `CoordinateLibrary` | `routeHistory` | 纯序列化/反序列化 | localStorage |
